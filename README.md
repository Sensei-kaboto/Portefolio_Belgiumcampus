# WPR181 Portfolio Website

A responsive personal portfolio website developed as a **group project for the WPR181 – Web Programming** course.

The purpose of this project is to apply the web development concepts learned throughout the course by designing and developing a professional portfolio website using **HTML, CSS **.

## 📌 Project Overview

This project involves creating a modern and responsive portfolio website that presents a student's personal information, skills, education, projects, and contact details.

The website is designed to demonstrate our understanding of fundamental web programming concepts, including:

* HTML5 structure and semantic elements
* CSS styling and layouts
* Responsive web design
* Navigation and hyperlinks
* Images and multimedia
* Forms
* Git and GitHub collaboration

## 🎯 Project Objectives

The main objectives of this project are to:

1. Apply the web programming concepts taught in WPR181.
2. Build a functional and responsive portfolio website.
3. Practice writing clean and well-structured HTML and CSS.
4. Implement interactive features 
5. Gain practical experience working with Git and GitHub as a team.
6. Develop good practices for collaborative software development.

## 🖥️ Website Features

The portfolio website includes the following sections:

* **Home** – Introduction and overview of the portfolio.
* **About Me** – Personal background and information.0
* **Portefolio** – Projects and work completed by the student.
* **Contact** – Contact information and/or contact form.

### Additional Features

* Responsive navigation
* Mobile-friendly layout
* Interactive elements
* Social media links
* Project cards
* Contact form
* Smooth navigation between sections

## 🚀 Getting Started

### 1. Clone the Repository

Clone the repository to your local machine:

```bash
git clone https://github.com/USERNAME/REPOSITORY-NAME.git
```

### 2. Open the Project

Navigate into the project directory:

```bash
cd WPR181-Portfolio
```

### 3. Run the Website

Open `index.html` in your browser.

Alternatively, if you are using **Visual Studio Code**, you can use the **Live Server** extension to run the website locally.

## 🔀 Git & GitHub Workflow

Since this is a group project, we use Git and GitHub to manage our work and collaborate.

### Recommended Workflow

Before starting work:

```bash
git pull origin main
```

Create a branch for your feature:

```bash
git checkout -b feature/your-feature-name
```

After making changes:

```bash
git add .
git commit -m "Add your feature description"
git push origin feature/your-feature-name
```

Then create a **Pull Request** on GitHub for the team to review before merging the changes into `main`.

### Branch Naming

We use descriptive branch names such as:

```text
feature/navigation
feature/home-page
feature/projects-section
feature/contact-form
fix/responsive-layout
fix/navbar
```

## 📋 Development Process

The project is developed through several stages:

1. **Planning** – Define the website requirements and structure.
2. **Design** – Create the layout and visual design.
3. **HTML Development** – Build the structure of the website.
4. **CSS Development** – Style the website and implement responsive layouts.
5. **JavaScript Development** – Add interactive functionality.
6. **Testing** – Test the website on different screen sizes and browsers.
7. **GitHub Collaboration** – Review, merge, and manage team contributions.
8. **Final Review** – Check the website against the WPR181 requirements.
